# 🌐 Site Web - GEIGE (Grande École d'Ingénierie et de Gestion)

Site web officiel de la Grande École d'Ingénierie et de Gestion (GEIGE) - Plateforme de présentation de l'établissement, des formations et de la vie étudiante.

## 🚀 À propos

Ce repository contient le code source du site web officiel de GEIGE. Le site a pour objectif de :
- Présenter l'établissement et ses valeurs
- Promouvoir les formations et programmes
- Faciliter les inscriptions et demandes de renseignements
- Informer sur la vie étudiante et les actualités
